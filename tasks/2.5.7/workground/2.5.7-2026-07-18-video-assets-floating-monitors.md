# 2.5.7 — Video assets and floating monitors

Date: 2026-07-18

## Request

- Import video assets, not only images/audio placeholders.
- Give every floating monitor its own source timeline.
- Allow adding a monitor to the main timeline.

## Delivered

- `Media > Video` imports MP4, MOV, and M4V into app-owned runtime media.
- Each asset opens a floating monitor editor with in/out trim controls.
- Adding a monitor creates a lane-aware `floating-monitor` region at the main playhead.
- Active monitor regions render in editor preview and WebCodecs export.
- Project save/import preserves monitor assets, trims, geometry, and timeline regions.

## Scope note

Monitor video is visual-only. Existing audio assets remain the explicit audio-mix path.
