# 2.5.7 — Video assets and floating monitors

Date: 2026-07-18

Update: 2026-07-19

## Request

- Import video assets, not only images/audio placeholders.
- Edit a video asset in a temporary full editor timeline, then return to the main project.
- Add the completed asset as a movable, resizable, crop-capable monitor on the main timeline.

## Delivered

- `Media > Video` imports MP4, MOV, and M4V. `Media > Image` imports PNG, JPG, JPEG, WEBP, and GIF.
- `Edit in timeline` replaces project preview/timeline with the asset's own editor state for video or static image. `Concluir edição` restores main project snapshot.
- Adding a monitor creates a lane-aware `floating-monitor` region at main playhead.
- Each monitor region owns position, size, crop, border/radius, flip, and shadow; preview drag handle moves/resizes it.
- Active monitor regions render in editor preview and WebCodecs export from the raw source or completed nested composition. The temporary asset timeline is isolated from the main composition; swapping is owned by the dedicated Swap region.
- Nested monitor regions now persist inside the asset timeline. Their composition receives global media sources, while the main screen is snapshotted before nested rendering; an image added inside the Kid Goku asset remains visible after `Concluir edição` and when reopening the asset editor.
- Monitor preview now uses the Blur-style selected geometry: center move control and eight edge/corner resize handles. Inactive monitor timeline blocks use the neutral border.
- Every `Edit copy in timeline` action clones the chosen image/video as `<original name> Edit`; the original asset remains unchanged. Monitor overlays show the immutable original-name badge above the asset.
- Edited clone cards show the green `Edit` badge over the thumbnail, top right. Original cards never receive it.
- Image monitor regions begin at five seconds and can be stretched to any duration allowed by the current timeline. Selecting a video monitor region adds the accent border/ring to its matching Media Assets card. Reopening an `Edit` asset edits that existing clone instead of creating another copy.
- Cursor style changes made while editing an asset are stored inside that asset and are restored on exit; `Show Cursor` no longer changes the main project or persisted appearance setting. The monitor inspector no longer contains `Swap with main video`; the Swap timeline region owns target selection for webcam, main screen, or a selected asset monitor.
- Dark mode: native text controls now use the dark color scheme and semantic foreground/caret colors; monitor/blur handles and monitor accents use theme tokens or lighter dark-mode violet to avoid black/low-contrast text and icons.
- Project save/import preserves assets, nested asset timelines, monitor geometry, crop, swap, and main timeline regions.

## Scope note

Monitor video is visual-only. Existing audio assets remain the explicit audio-mix path.
